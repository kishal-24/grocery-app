# 🛒 Grocery Shopping App

A modern grocery shopping mobile application developed using **Flutter** and **Dart**.

The project is designed to provide users with a simple and convenient way to browse grocery products, search for products, add products to a cart, manage a wishlist, and complete orders.

The application uses **BLoC architecture** to separate the user interface from the business logic.

---

# 📱 Project Explanation

The Grocery App is an e-commerce application for buying grocery products online.

A user can go through the following flow:

```text

      ↓

      ↓
